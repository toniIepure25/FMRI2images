# outputs/

Runtime output directory for all pipeline stages. Contents are **not git-tracked**
(regenerated by the pipeline). Only this README is versioned.

## Directory Structure

```
outputs/
├── clip_cache/          # CLIP embedding caches (parquet)
├── eval/                # Evaluation metrics and summaries
├── preproc/             # fMRI preprocessing artifacts (PCA, scalers, masks)
├── recon/               # Diffusion reconstruction images and manifests
├── reports/             # Aggregated evaluation reports, figures, CSVs
└── README.md            # This file (git-tracked)
```

## Phase 2 Conventions (B0--N4)

All new experiment outputs use the B0/B1/N1--N4 naming from
`configs/experiments/`. Expected layout for a training run:

```
outputs/
├── clip_cache/
│   ├── clip_meta.json                    # model name, dim, pretrained source
│   ├── subj01_clip768.parquet            # ViT-L/14 embeddings (768-D)
│   └── target_clip_sd21.parquet          # SD 2.1 target latents
├── preproc/
│   └── subj01/
│       ├── meta.json                     # n_voxels, pca_k, rel_threshold
│       ├── pca_components.npy
│       ├── pca_mean.npy
│       ├── scaler_mean.npy
│       ├── scaler_std.npy
│       ├── voxel_indices.npy
│       └── reliability_mask.npy
├── eval/
│   └── subj01/
│       └── <experiment>/
│           ├── evaluation_summary.json
│           ├── metrics_per_sample.csv
│           └── *.png
├── recon/
│   └── subj01/
│       └── <experiment>/
│           ├── decode_summary.json
│           ├── images/
│           └── paper_assets/
└── reports/
    └── subj01/
        └── <experiment>/
            ├── recon_eval_summary.md
            ├── recon_eval_matched.csv
            └── recon_grid_matched.png
```

## Regeneration

To rebuild from scratch after cleanup:

```bash
# 1. Preprocessing
python3 scripts/preprocessing/preprocess_fmri.py --config configs/base.yaml

# 2. CLIP cache
python3 scripts/preprocessing/build_clip_cache.py --config configs/system/clip.yaml

# 3. Training (generates eval/ outputs)
python3 scripts/training/train_unified.py --config configs/experiments/B0_deterministic.yaml

# 4. Reconstruction
python3 scripts/reconstruction/decode_diffusion.py --config configs/inference/production.yaml
```
