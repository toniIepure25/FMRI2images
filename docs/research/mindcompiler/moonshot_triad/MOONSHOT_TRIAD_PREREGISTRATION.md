- **M1 — Geometry-Aware Adaptive Calibration (shadow).** *Can we know online when we have enough imagery
  calibration data?* A shadow policy runs alongside the frozen acquisition, never changes it, and emits
  STOP/CONTINUE using only information up to observation t (never future/held-out outcomes). Stops when the
  accumulated outside-support subspace stops improving. Status: `M1_SHADOW_ADAPTIVE_PROTOCOL_READY`.
- **M2 — Zero / near-zero shot geometry prediction.** *Can we predict the subject-specific missing imagery
  geometry before direct calibration?* Strict participant-disjoint (LOSO) prediction from richer non-imagery
  descriptors, with a bounded low-capacity model appropriate for N ≈ 12 (ridge + low-rank; identifiability
  audit). Two protocols (zero-target, near-zero-target) reported separately; permuted-participant null. Status:
  `M2_ZERO_SHOT_PROTOCOL_READY`.
- **M3 — Cross-state shared-scaffold / private-correction.** *Does the same structure appear in another
  internally generated state (delayed recall)?* A **separate post-replication** memory-reinstatement block that
  **does not modify O2.16**; cross-state geometry decomposition. Status:
  `M3_CROSS_STATE_PROTOCOL_READY_FOR_HUMAN_REVIEW`.

for anything but large, consistent effects is very limited. Moonshots are **discovery** on Cohort B and
**require Cohort C** to confirm.
