# Post-PI decision tree

No branch changes the frozen scientific outcomes; scientific changes go through change control.

- **PI interested + site available** → complete site config → transfer ethics package → hardware dry-run → engineering pilot → Cohort B.
- **PI interested + different site recommended** → re-verify that site (official sources) → new candidate site config → continue.
- **PI interested + major scientific concerns** → log via HUMAN_FEEDBACK_TEMPLATE → change-control review → decide if preregistration still valid or a new protocol version is needed (never silent edit).
- **PI interested but no MRI access** → keep PI as scientific supervisor → approach a facility PI (Windischberger/Lamm) for access.
- **PI declines but refers someone** → thank + add referral to shortlist (verify) → send Wave-appropriate bundle.
- **No response** → follow-up after 5-7 working days → then Wave 2.
- **Site says 3T only** → acceptable; record as site constraint; do not change frozen design; note field-strength in the manuscript.
- **Site says 7T possible** → evaluate operational cost vs benefit with the MR physicist; still no design change for outcomes.
- **Ethics requires modifications** → classify (administrative/engineering/acquisition/scientific) via change control; amend forms; only scientific-primary changes touch the protocol version.
- **Stimulus license blocker** → resolve permissions or finalize the 12 imagery identities with cleared licenses before confirmatory; pilot may proceed on cleared stimuli only.
