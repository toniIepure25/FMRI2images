# 60-second spoken pitch

Problem: when we picture something in our mind, visual cortex activity looks like perception — but not exactly,
and decoding imagery is limited by how much imagery data you must collect per person.

Finding: in eight participants, perception explains a lot of the imagined state but not all; the missing part is
low-dimensional but specific to the individual, and a small amount of direct imagery data recovers it.

Limitation: it is eight people, one dataset, and the calibration is fragile — which particular measurements you
take matters.

Replication: so I've frozen and preregistered an independent replication in a new cohort.

Ask: I'm looking for a supervisor and MRI access to run it — and, first, honest scientific feedback.
