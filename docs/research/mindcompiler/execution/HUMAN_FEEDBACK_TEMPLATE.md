# Human feedback log template

For each piece of PI/reviewer feedback, record:

| field | value |
|---|---|
| source (name/role) | |
| date | |
| verbatim concern | |
| category | FATAL_SCIENTIFIC / MAJOR_SCIENTIFIC / METHOD / ACQUISITION / STATISTICAL / PRESENTATION / OPTIONAL_IMPROVEMENT / SITE_REQUIREMENT / ETHICS_REQUIREMENT |
| affects frozen O2.16? | yes/no |
| change-control class | (see CHANGE_CONTROL_POLICY) |
| decision | accept / defer / decline (with reason) |

**Human feedback is not automatically implemented.** Scientific changes go through change-control review; the
frozen protocol is never silently modified.
