# Experiments (draft)

This page indexes the experimental evidence used for `docs/paper/claims.md`.

## Experiment cards

Add one card per experiment under `docs/paper/experiments/`.

Each card should include:

- exact command line or Makefile target
- config snapshot / overrides
- expected artifacts (paths)
- manifest location
- results table/plot references

Start from the template: `docs/paper/experiments/TEMPLATE.md`.
