# Baseline empty-prompt reconstruction (archived)

These artifacts come from the first iteration of `scripts/evaluation/run_triple_reconstruction.py`,
which ran SD 2.1 img2img with `prompt=""` and fixed per-bucket routes
(`identity_pass / low_strength_refine / guided_refine / exploratory_refine`).

They are retained for transparency only. The thesis (Table 5.5 and surrounding
narrative in chapter 5) reports the CLIP-conditioned best-of-16 results in
`../metrics_summary.json` and `../per_example.csv`, generated by the upgraded
pipeline (Tiers 1, 2, 3, 5) with `method == "clip_conditioned_best_of_n_ua_strength"`.

| File | Pipeline |
|---|---|
| `metrics_summary.json`        | empty prompt, fixed bucket routes |
| `per_example.csv`             | empty prompt, fixed bucket routes |
| `selected_examples_triple.csv`| same 16 NSD ids as the headline run |
