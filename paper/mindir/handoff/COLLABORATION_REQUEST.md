# Collaboration request

This is an MSc Cognitive Science project. The discovery phase is complete and written up; the natural next step
requires independent data and senior scientific oversight. We are seeking help with some or all of the
following. None of these is contingent on offering authorship in exchange for access.

**A. Scientific feedback on the discovery manuscript.** An honest read of the argument, the statistics (N = 8;
participant-level inference), the claim boundaries, and whether the framing relative to prior work is fair.

**B. A supervisor / PI to evaluate the independent replication.** Someone willing to assess the frozen,
preregistered replication design and judge whether it is worth running.

**C. MRI facility access.** Access to a suitable scanner (7T preferred where feasible) to acquire a genuinely
independent cohort, if the design is judged sound.

**D. Guidance / sponsorship for ethics submission.** Help navigating and, where appropriate, sponsoring an
ethics application for the new cohort.

**E. Coauthorship — only if scientifically warranted.** Coauthorship would be offered only on the basis of
genuine scientific contribution (design input, oversight, data, analysis, or writing), consistent with standard
authorship criteria. **Facility access alone is not a basis for authorship**, and we are not proposing to trade
authorship for access.

We are happy to start with (A) — feedback — with no further commitment, and to discuss (B)–(E) only if the work
is judged worth pursuing.
