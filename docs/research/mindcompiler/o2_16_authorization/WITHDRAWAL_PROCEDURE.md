# Withdrawal procedure

> **DRAFT_FOR_HUMAN_REVIEW.** No approval (PI, ethics, site, data-protection, consent, stimulus licence) has been granted. This is a draft to be transferred into the institution's official forms.


- **Before scanning:** withdraw freely; no data retained.
- **During scanning:** stop immediately on request; partial data deleted or retained per participant choice and
  site policy.
- **After scanning, before analysis:** data removed on request where still identifiable via the key.
- **After irreversible anonymization/aggregation:** removal may not be possible, **subject to institutional
  rules** (`REQUIRES_INSTITUTIONAL_REVIEW`). Communicated clearly in consent.
All legally sensitive statements are provisional pending ethics/data-protection review.
