# M3 — Cross-state protocol (for human PI / ethics / site review)

> **Status: `M3_CROSS_STATE_PROTOCOL_READY_FOR_HUMAN_REVIEW`.** This is a prospective protocol, not a result.
> It **does not modify the O2.16 acquisition** in any way and must not be run until a human PI approves it, an
> ethics amendment covers the added block, and the site can schedule it.

## Question
Does the shared-scaffold + private-correction structure found for imagery geometry recur in **another internally
generated state** — delayed visual recall / memory reinstatement — rather than being specific to imagery?

## Design (separate post-replication block)
- A **delayed visual recall / memory-reinstatement** task: participants later recall previously seen anchor
  content on cue, producing a "recall-state" neural pattern per identity.
- Run as a **separate block or session AFTER** the O2.16 replication acquisition is complete for a participant.
- The O2.16 perception and imagery tasks, endpoints, estimator, folds, randomization, and all frozen parameters
  are **unchanged**; M3 adds a block, it does not alter O2.16.

## Cross-state analysis (post-unlock only)
- Decompose each state's target geometry into a **shared-scaffold** component (common across imagery and recall)
  and a **private-correction** residual (state/participant-specific).
- Generalization = the shared scaffold recurs across states while private corrections remain subject-specific.
- Prospective null: no-shared permutation. Participant is the inferential unit. Any Cohort-B result requires an
  independent Cohort C to confirm.

## What human review must decide before M3 can run
- PI scientific approval of the added block and its analysis plan.
- **Ethics amendment/approval** to add the recall block (extra time, extra task).
- Site/session scheduling feasibility (a second block or session).
- Stimulus permissions for recall cues.
- Participant-burden assessment (total scan time with the added block).

## Guards
No modification of O2.16; no historical-N8 data; no outcome access before the O2.16 unlock chain; predictor-side
/ protected-outcome firewall; bounded analysis; multiple-testing family within M3; Cohort-C confirmation
template attached. Until approved and run on real data, M3 remains a protocol awaiting human review — never a
result.
