# Decision-focused questions for the PI

1. Is the scientific framing strong enough for a thesis / publication?
2. Which claim do you find least convincing?
3. Would you support an independent replication?
4. Is 3T sufficient, or should we seriously pursue 7T?
5. What acquisition changes would you recommend before ethics?
6. Which MRI facility would you use?
7. Is the proposed N≈12 realistic operationally (recruitment, scanner time)?
8. What behavioral measures would add genuine value (e.g. vividness, recall accuracy)?
9. What is the correct ethics pathway at your institution?
10. Who should be involved technically (MR physicist, operator)?
11. Would you recommend repeated sessions (for the cross-session fingerprint / zero-shot ideas)?
12. Should the delayed-recall (cross-state) block be included now or reserved for a later cohort?
